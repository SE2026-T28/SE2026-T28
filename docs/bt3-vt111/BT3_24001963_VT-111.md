## 1. Specification (rút gọn từ `spec.md`)

**Problem statement.** Repo baseline chưa có khái niệm role: model `User` chỉ có `id, email, passwordHash` (`identity-server/prisma/schema.prisma:10-18`). Slice thêm module `identity-server/src/review/` với resource `ReviewItem` (`data={title,body}`, `status`, `version`) và Express router `createReviewRouter({store, resolveActor, beforeCommit?})`. `admin` đọc và sửa `data`; `reviewer` đọc và approve/reject nhưng không bao giờ ghi `data`; role khác bị deny. Rủi ro: hai approve/reject (hoặc PATCH chen vào lúc review) cùng lúc gây lost update hoặc một item bị quyết định hai lần. Store in-memory, không Prisma, router chưa mount vào `src/app.ts`.

| AC | Nội dung (Given/When/Then rút gọn) |
|---|---|
| AC1 Đọc | `admin`/`reviewer` GET `/review-items/:id` -> 200 `{item}` + `ETag: "v1"`; role khác 403, không token 401, id lạ 404. |
| AC2 Approve giữ data | reviewer POST `/decision` `{approve}` + `If-Match:"v1"` + `Idempotency-Key` -> 200, `status=approved`, `decidedBy`, `decidedAt` (clock inject), `version=2`, `data` byte-identical (`JSON.stringify`). `reject` tương tự. |
| AC3 Reviewer không sửa | reviewer PATCH -> 403, `data`/`version` không đổi; admin POST decision -> 403 (separation of duties). |
| AC4 Một request thắng | N=2 và N=60 request cùng `If-Match:"v1"`, key khác nhau, `Promise.all`, qua `beforeCommit` bất đồng bộ -> đúng 1 x 200, N-1 x 412, `version=2`, không lost update. PATCH admin đồng thời: 1 x 200, còn lại 412. |
| AC5 Idempotent | cùng key + cùng fingerprint (itemId+decision+If-Match) -> replay status/body đã lưu, không apply lần hai; cùng key khác fingerprint -> 422; request đầu còn chạy -> 409; thiếu key -> 400. |

**NFR.** NFR1: 60 request đồng thời qua HTTP thật, p95 nearest-rank (rank 57) <= 2.0 s, ghi p50/max/lỗi; client và server chung event loop nên số đo lạc quan (`research.md` mục 6). NFR2: offline, deterministic (clock/token inject, không `Math.random`), suite < 10 s. NFR3: deny by default (không actor -> 401, role lạ -> 403), role chỉ từ `resolveActor(req)`, không log token.

**Invariant.** `data` chỉ đổi qua PATCH của `admin` có `If-Match` khớp; mỗi chuyển version v -> v+1 apply tối đa một lần; item `pending` được quyết định tối đa một lần. Cơ chế: `store.compareAndSet` kiểm version và ghi trong một đoạn đồng bộ (không `await`), idempotency key được reserve đồng bộ trước `await` đầu tiên. Thứ tự kiểm tra POST decision: 401 -> 403 -> 404 -> 400 (thiếu key) -> 428 (thiếu If-Match) -> 400 (decision sai) -> idempotency -> 412 -> 409 -> CAS.

## 3. Risk-based test strategy

**Xếp hạng rủi ro:** (1) race gây lost update/double decision; (2) reviewer sửa data gốc hoặc admin tự approve; (3) retry/key misuse; (4) sai mã trạng thái (428/412/409/422/400).

**Phân bổ level.**
- **Unit** (`test/review-store.test.ts`): `compareAndSet` (version đúng/lệch, mutate không chạy khi lệch, hai lần gọi đồng bộ liên tiếp), store trả bản copy, idempotency reservation. Kỹ thuật: boundary + state-based.
- **API** (`review-authz.test.ts`, `review-concurrency.test.ts`): mount router lên `express()` mới, `listen(0, "127.0.0.1")`, `fetch` thật; `beforeCommit` inject (no-op / `setImmediate` / gate Promise / throw); clock inject.
- **Load**: harness `scripts/review-load.mjs` riêng (đo thời gian, không phải đúng/sai chức năng); TC-09 kiểm tính đúng của 60 concurrent, không đo thời gian.
- **E2E: không cần và không thể.** Router chưa mount vào `src/app.ts`, chưa có đăng nhập reviewer (không có cột role, không UI); thêm E2E phải đổi schema/OIDC (xem P3, P7). Mọi hành vi đã phủ ở tầng API với HTTP thật.
- **Không test (limitation):** persistence Prisma/Postgres, race giữa nhiều process, TTL idempotency, token thật qua oidc-provider, TLS.

**Decision table** (Role: admin/reviewer/other/none; If-Match: missing/stale/current; Key: missing/new/replay-same/replay-different; Status: pending/decided). Đủ 4x3x3x4x2 = 288 cột, gộp còn 17 rule vì authn/authz chạy trước mọi điều kiện, GET không đọc If-Match/Key, PATCH không dùng Key, replay/in-flight xử lý trước 412/409 (`spec.md` mục 7).

| R1 | none | - | - | - | - | 401 |
